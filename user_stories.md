# Admin User Stories

## User & Access Management
- As an Admin, I want to create, update, and deactivate user accounts (Patients and Doctors), so that only authorized individuals can access the system.
- As an Admin, I want to assign roles and permissions to system users, so that data security and privacy compliance are maintained across the platform.
## System & Master Data Maintenance
- As an Admin, I want to manage doctor profiles and specializations, so that accurate directory details are displayed to patients.
- As an Admin, I want to view system logs and audit trails, so that I can monitor platform activity, troubleshoot issues, and track administrative actions.

# Patient User Stories
## Appointment Booking & Management
- As a Patient, I want to search for doctors by specialty and view their real-time availability, so that I can select a suitable time for an appointment.
- As a Patient, I want to book, reschedule, or cancel an appointment via the mobile app or web portal, so that I can manage my healthcare schedule conveniently.
## Medical History & Prescriptions
- As a Patient, I want to access my past appointment history and medical records, so that I can keep track of my healthcare journey.
- As a Patient, I want to view and download my digital prescriptions (stored in MongoDB), so that I can easily purchase medications or share details with my pharmacy.

# Doctor User Stories
## Schedule & Availability Management
- As a Doctor, I want to set and update my available working hours and consultation slots, so that patients can only book appointments when I am free.
- As a Doctor, I want to block out personal time off or emergency breaks on my schedule, so that overlapping appointments are automatically prevented.
## Patient Consultations & Prescriptions
- As a Doctor, I want to view my daily list of upcoming appointments and patient details, so that I can prepare for consultations efficiently.
- As a Doctor, I want to issue and save digital prescriptions directly to a patient's record after a consultation, so that their treatment plan is documented securely.
